# Technical Writing Quiz

100 bilingual (English / Arabic) practice questions in 4 parts, built with Next.js (static export).

## Run locally
npm install
npm run dev

## Deploy on GitHub Pages
1. Push this folder to a GitHub repo (branch `main`).
2. Repo > Settings > Pages > Source: **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` builds and publishes the site on every push.
